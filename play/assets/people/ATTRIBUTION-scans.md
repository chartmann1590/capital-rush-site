# People pack 2 — attribution

All models below were obtained from Sketchfab under the Creative Commons Attribution 4.0 licence (licence verified on each model page via the Sketchfab model API). Each was adapted for this game: rebound to the MakeHuman `game_engine` 53-bone skeleton, rescaled to metres, decimated to <=20k triangles with an extra LOD, textures re-packed into a single atlas (WEBP).
